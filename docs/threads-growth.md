## 1. アルゴリズムの要点

| 項目 | 内容 | 確度 |
|---|---|---|
| 返信（会話）が最重要 | いいねより「返信が往復する会話」が伸びの中心。Mosseri氏も返信の価値を重視する発言あり | 高 |
| 初速 | 投稿後30〜90分の反応で拡散範囲が決まるとされる。最初の1時間は自分も返信する | 中〜高 |
| 新しさ | 新しい投稿が優先される。おすすめは「いいね・返信・フォロー・プロフ遷移の予測値」で配信 | 高 |
| テーマの一貫性 | 発信テーマを絞るほど「誰に届けるか」が学習されやすい（カテゴリ3つ以内推奨の記事あり） | 中 |
| トピックタグ | 1投稿に1つ。トピックフィードに載る可能性。効果の大きさは記事により見解が割れる | 中 |
| 外部リンク | 2025年にURL付き投稿の減点をやめた／むしろ評価を上げたとの報道。ただし現場では「本文はリンクなし→返信欄にリンク」が今も主流 | 中 |
| ユーザー側の制御 | 2026年に「Dear Algo」等、ユーザーがフィードを調整できる機能が出たとの報道（未検証） | 低 |

## 2. やるべきこと（優先順）

1. **プロフィールを「誰の・何の役に立つか」1行で言い切る**
   - 例：「非エンジニアの会社員が、生成AIで毎日1時間浮かせる方法を発信」
   - 実績の数字・発信頻度・固定投稿へ誘導。
2. **固定投稿を作る**：自己紹介＋代表的な有益投稿 or 無料特典。プロフ訪問者をフォローに変える場所。
3. **発信の柱を2〜3本に絞る**（AIアカウントなら例）
   - 具体的な使い方（プロンプト・手順・ビフォーアフター）
   - 最新ニュースの「自分の言葉での解釈」（速報の転載ではなく一言意見）
   - 体験談・失敗談（人柄が出る投稿＝フォローされる理由）
4. **冒頭1〜2行で結論 or 問い**：「続きを読む」を押させる改行。長文より読み切れる長さ＋返信したくなる余白。
5. **投稿末尾に「答えやすい質問」**：「あなたはどっち派？」「使ってるAIツール1つ教えて」など、Yes/No・一言で答えられる問い。
6. **返信はすべて返す（特に最初の1時間）**：会話の往復そのものが評価対象。
7. **伸びている同ジャンル投稿に、中身のある返信をする**：大手アカウントの返信欄は最大の露出場所。「わかる」ではなく具体的な補足や体験を書く。
8. **毎日投稿（1日1〜3回）＋時間帯を固定**：通勤・昼休み・夜21〜23時あたりで試し、インサイトで反応の良い時間に寄せる。
9. **トピックタグを毎回1つ付ける**（「AI」「ChatGPT」「生成AI」など、狙うフィードに合わせて固定気味に）。
10. **インサイトで週1振り返り**：閲覧数より「返信数」「フォロー転換」を見る。伸びた投稿の型を再利用する。

## 3. やめるべきこと・変えるべきこと（よくある失敗）

- ニュースの転載・英語記事の翻訳だけ（AIジャンルは供給過多。意見や実体験がないと埋もれる）
- AIで生成したままの文章（「〜しましょう！」「いかがでしたか」系の定型文は読まれない／Metaも低品質AI投稿対策を明言）
- 毎回本文に外部リンク、宣伝比率が高すぎる（目安：有益8：告知2）
- ハッシュタグ乱用・テーマがバラバラ
- 投稿しっぱなしで返信しない
- 自動返信・一括フォローなどの自動化ツール（規約リスク）

## 4. AIジャンル向け投稿の型（テンプレ）

- **比較型**：「ChatGPTとClaudeに同じ依頼をしたら、こう違った」
- **手順型**：「〇〇を5分で終わらせるプロンプト（コピペOK）」→ 返信欄に続き
- **失敗談型**：「AIに任せて失敗したこと3つ」
- **問いかけ型**：「仕事でAI、正直どこまで使ってる？」
- **ニュース解釈型**：「〇〇が発表。一般の会社員にとって意味があるのはここだけ」

## 5. 次にやること（要：アカウントの実データ）

実際の改善提案には以下が必要：
- プロフィール文・固定投稿のスクショ

- フォロワー数の推移、目的（認知／集客／収益化）

### 診断
1. **反応がほぼゼロ → おすすめ配信が初動で止まっている。** 見せられても「いいね・返信」が付かないので次に広がらない。
2. **一般論の健康Tipsで、誰が言っているかが見えない。** 腸活・ファスティング・夜食は供給過多のテーマ。肌管理サロンの現場目線や実体験・数字が無いと差別化できない。
3. **返信したくなる余白が無い。** 言い切りで終わっていて、読者が書き込む理由が無い。
4. **投稿の空白期間**（10/14〜22）で配信の学習がリセットされた可能性。
5. **フォロワーが一桁台のうちは、自分の投稿より「他人の投稿への返信」の方が露出が大きい。**
6. LINE誘導はまだ早い（クリック1）。まずフォロー理由を作る。
7. 健康・美容の効果表現は薬機法・景表法に注意（「治る」「必ず痩せる」等は避ける）。

### 次の2週間でやること
- 伸びた投稿（10/12前後）を「閲覧数が多い順」で特定し、型を分解して再現する。
- 毎日：同ジャンル（美容・肌管理・腸活）の伸びている投稿に、現場目線の具体的な返信を5〜10件。
- 投稿は1日1〜2本、空白日を作らない。トピックタグは「美容」か「スキンケア」に固定。
- 本文を「一般論」→「サロンで見た事例・自分の体験＋具体的な数字」に変える。
- 最後に一言で答えられる質問を置く（例：「朝ごはん、食べる派？抜く派？」）。
- 返信が来たら1時間以内に必ず返す。
