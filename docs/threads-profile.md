# Threads プロフィール設計（@kudooo_ai）2026-11-13

## 前提（サイトから分かること）
- 二子玉川の肌管理サロン「美yond（BEYOND）」。営業 10:30〜22:00。
- 考え方は「美yondメソッド」：サロンの**攻めのケア**／ご自宅の**守りのケア**／食事など**内側からのケア**。
- 投稿テーマ（腸活・食事・スキンケア・ファスティング）はこの3つにそのまま当てはまる。
- 未確認：かけるの立場（オーナー？施術者？）、資格・経歴、施術人数などの実績数字。

## 設計の方針
1. **個人として発信し、サロンを裏付けにする。** 人は店より人をフォローする。「サロン公式」ではなく「サロンの中の人」。
2. **誰向けか**：二子玉川周辺〜都内で、肌荒れ・毛穴・くすみが気になるけど、ストイックなケアは続かない30〜40代。（投稿の「ズボラ」「料理しなくても」と一致）
3. **差別化**：肌を「塗るもの」だけで考えず、施術・ホームケア・食事の3つで見る現場の人。男性の発信者なら、それ自体も目立つ要素になる。
4. **約束**：「頑張らなくても続く肌ケア」を毎日発信する。

## ⑤ 固定投稿（プロフィールを見た人をフォローに変える場所）
```
はじめまして、二子玉川で肌管理サロン「美yond」をやっている、かけるです。

毎日お客さんの肌を見ていて思うのは、
肌が変わる人は「高いケアをしている人」じゃなくて
「続けられることだけやっている人」だということ。

なのでこのアカウントでは
・サロンでやること（攻めのケア）
・おうちでやること（守りのケア）
・食べるもの（内側のケア）
この3つの「これだけでいい」を発信しています。

今いちばん気になっている肌の悩みを、返信で教えてください。
投稿のネタにして答えます。
```
→ 最後の問いかけで返信を集め、返ってきた悩みをそのまま次の投稿ネタにする。
